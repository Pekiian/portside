Ten containers, one process

Docker Desktop serves every published port from one process, so the tools underneath show ten identical rows. Portside asks Docker which container is on each port.

What else it does

Localhost only
Loopback and wildcard binds. LAN, link-local, and UDP never appear.
Names, not pids
Rows say storefront, read from the working directory and package.json, instead of node.
Pin and rename
Keep :5432 at the top and call it work db. Pinned ports stay in the list when they stop.
Kill without a terminal
SIGTERM, then SIGKILL after three seconds.
Quiet
No dock icon, no accounts, no telemetry. Polling stops while your Mac sleeps.

Install

Clone it and run the build script. It builds the app and puts it in /Applications.

git clone https://github.com/Pekiian/portside && cd portside && ./build.sh --install

Requires macOS 14 or later and the Swift toolchain.

Reads lsof, ps, and Docker's local socket. Makes no network calls. github.com/Pekiian/portside
